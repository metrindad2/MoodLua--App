# **App Name**: CycleGuard

## Core Features:

- User Onboarding & Profile Setup: Guides first-time users to input crucial cycle data (last menstruation date, flow duration, average cycle length) to personalize initial predictions.
- Menstrual Cycle Prediction: Calculates and displays predicted ovulation days, upcoming PMS windows, and overall cycle phases based on user-provided and logged data.
- Daily Tracking Log: Allows users to log daily menstrual flow intensity (light, medium, intense) and various symptoms like headaches, cramps, and mood via a dedicated '+' icon.
- Menstruation Start/End Registration: Enables users to accurately mark the beginning and end dates of their menstruation via a prominent button on the main screen.
- Interactive Cycle Calendar: Provides a visual calendar displaying predicted menstrual days (red), fertile window (green), and probable ovulation day (highlighted) for easy overview.
- Personalized Cycle Insights Tool: A generative AI tool that analyzes logged symptoms, mood, and cycle history to provide personalized insights, potential correlations, and wellness suggestions.
- Emergency SOS Functionality: Implements a two-tap emergency button that automatically calls police, sends user's location, and a customizable alert message to pre-configured emergency contacts.

## Style Guidelines:

- Primary color: Deep royal purple (#6A0DAD) for key headings and prominent UI elements, providing an authoritative and feminine touch, as specified by the user.
- Background color: A soft, very light lavender (#ECE6F1) derived from the primary hue, providing a clean, serene, and calming backdrop.
- Secondary color: A calming mid-tone blue (#5C80DB) for supporting information, icons, and complementary interactive elements, enhancing readability, as requested by the user.
- Accent color: A vibrant feminine pink (#EC80CC) specifically designated for primary call-to-action buttons, ensuring high visibility and an inviting feel, as requested by the user.
- Headline and body font: 'Inter', a modern sans-serif, chosen for its clear legibility, neutrality, and professional appearance across various content types, aligning with a simple and intuitive design.
- Utilize simple, line-art style icons that are easily recognizable for daily logging (e.g., '+'), calendar views, mood indicators, and the prominent SOS button. Icons should be clear and not overly detailed.
- The interface will feature a modern, clean, and intuitive layout. Summary views will use a card-based structure. Essential navigation (daily tracking, calendar, history) will be accessible via a clear bottom navigation bar. The SOS button will be persistently visible for quick access.
- Implement subtle, fluid animations for screen transitions and content updates. Button presses will have small, quick feedback animations to indicate interaction, ensuring a smooth and responsive user experience.
